# codex checks

i want to create a cli app which just checks codex and chatgpt status,
like my hourly/weekly limits, how much i've used, when they reset, etc...
basically a monitor for my codex and chatgpt usage metadata.

we will use github.com/spf13/cobra and github.com/openai/openai-go/v3
and xoba.com/keep for api credentials. use "keep" binary on the path for
the admin functions of enrolling this app into keep central.
